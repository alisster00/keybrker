# KeyBrker

Simple generador de contraseñas con un simulador de ataque de fuerza bruta.

## Requisitos Previos

Asegúrate de tener instalado:
- Python 3.x

## Instalación y Ejecución

Sigue estos pasos para ejecutar el proyecto:

1. **Clona el repositorio**:
   ```bash
   git clone https://github.com/alisster00/keybrker.git
   ```

2. **Accede al directorio del proyecto**:
   ```bash
   cd keybrker
   ```

3. **Ejecuta el script principal**:
   ```bash
   python app.py
   ```

## Notas Adicionales

- Si el script no requiere dependencias externas.
- En sistemas Linux/Mac, es posible que debas usar `python3` en lugar de `python`.
